# Ködade Homebrew tap

Homebrew formulas for Ködade tools.

```sh
brew install kodade/tap/kodade-cli
```

After that, `brew upgrade` picks up new releases like any other package.

`Formula/kodade-cli.rb` is generated by the release workflow in
[Kodade/kodade-cli](https://github.com/Kodade/kodade-cli) from each release's
`SHA256SUMS`; do not edit it by hand.
